# Collatz Research v2.3

This supplement preserves the author-run Lean research modules for affine descent, parity rigidity, parity complexity, binary stabilization, first-crossing and stopping-time arithmetic, and positive-cycle restrictions. It does not replace the v2.2 Lean project or its archived evidence.

**Scope:** the Collatz conjecture is not proved or disproved. The audited statements are verified under their explicit hypotheses. Universal descent, divergent trajectory exclusion and nontrivial positive cycle exclusion remain open. Analytical arguments, published computational verification bounds and conditional numerical estimates discussed during research are not certified in their entirety by these audits. No claim of originality or independent peer review is made.

## Audit

The audit logs were generated by running `lake env lean` separately on each source in the author's existing working environment. Each successful command was checked for exit status, expected number of axiom-audit entries, absence of `sorryAx`, and reported axiom names limited to `propext`, `Classical.choice`, and `Quot.sound`. This is an audit of selected declarations, not all declarations or a full-project build. Nonfatal stylistic warnings may appear in the logs.

## Reproduction

Install Lean/elan and Git. The copied `lean-toolchain`, Lake configuration and manifest record the author's working environment. In this folder, use `lake exe cache get` to retrieve Mathlib cache if needed, then run `lake env lean <module>.lean` on the listed files. Do not replace the pinned manifest with `lake update` unless intentionally updating dependencies. This supplement is intended for individual-file audits; the legacy Lake default build target may require the original project modules. A clean independent rebuild of this packaged supplement has not yet been performed.

See `audit/environment.txt`, the individual audit logs, and `SHA256SUMS.txt` for source integrity. This supplement contains only the Lean research files and audit evidence; the broader manuscripts remain in the parent repository.
